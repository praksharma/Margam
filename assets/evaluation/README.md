# Supplied-point example data

These tiny files are generated analytical demonstration data for the 1D Poisson
problem uₓₓ+2=0 on [0,1], u(0)=u(1)=0. The reference is u=x(1−x).
`supplied-points.csv` deliberately has non-sorted coordinates and text IDs;
`reference-values.csv` deliberately reorders the same IDs/coordinates.
They are not imported FEM results or paper benchmark datasets.
