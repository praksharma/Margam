# Prepared triangular-domain fixture

Independently generated demonstration data on x≥0, y≥0, x+y≤1.
The manufactured solution is u=x²+y², so Δu−4=0.
The base has Dirichlet data u=x²; the upright edge has outward derivative zero;
the sloped edge has outward derivative √2 with normal (1,1)/√2.
Boundary rows exclude vertices. Evaluation rows include the three vertices and
55 interior locations with explicit IDs. This is a data-contract fixture, not
paper/FEM data or a tuned accuracy benchmark. No topology is supplied.
